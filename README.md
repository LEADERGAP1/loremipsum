 Ejercicios clásicos con Bash y archivos de texto

Este repositorio contiene una serie de ejercicios prácticos orientados al uso de scripts en Bash y manipulación de archivos de texto en Linux.

La idea de este trabajo es reforzar conceptos básicos pero fundamentales, como:

- navegación y trabajo en consola
- lectura y procesamiento de archivos
- automatización mediante scripts .sh
- conteo y análisis de texto
- práctica de lógica aplicada en entornos Unix/Linux

Contenido del repositorio:

Los archivos incluidos actualmente son:

- contar.sh → script orientado al conteo o análisis de contenido
- ipsum.sh → script relacionado con procesamiento/generación de texto
- loremipsum-1.txt
- loremipsum-2.txt
- loremipsum-3.txt
- loremipsum-4.txt
- loremipsum-5.txt

Estos archivos de texto se utilizan como base para ejecutar y probar los scripts.

Objetivo:

El objetivo principal de estos ejercicios es practicar el uso de herramientas típicas de Linux para resolver problemas simples de forma automatizada.

Este tipo de prácticas ayuda a desarrollar habilidades importantes como:

- interpretación de requerimientos
- escritura de scripts reutilizables
- organización de archivos
- uso eficiente de la terminal
- comprensión del flujo entre entrada, procesamiento y salida

Requisitos:

Para ejecutar estos ejercicios se necesita:

- un sistema operativo Linux o Unix-like
- terminal Bash
- permisos de ejecución sobre los scripts

Ejecución:

Antes de ejecutar los scripts, dar permisos con:

bash
chmod +x contar.sh ipsum.sh

Luego pueden ejecutarse con:

./contar.sh
./ipsum.sh

ó también:

bash contar.sh
bash ipsum.sh


Propósito académico

Este repositorio fue realizado como práctica de ejercicios clásicos de programación y scripting, con el fin de afianzar conocimientos básicos de entorno Linux, Bash y manejo de archivos.

Más que un proyecto grande, se trata de una base de entrenamiento útil para mejorar lógica, prolijidad y dominio de herramientas esenciales.
